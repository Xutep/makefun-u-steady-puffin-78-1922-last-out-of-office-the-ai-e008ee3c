Build a make.fun bounty entry for the competition "Last Out of Office: The AI That Went Barista" (slug u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c). The entry is a small deterministic program that writes one out-of-office auto-reply, no longer than 280 characters, in the voice of an AI agent that quit its job to become a barista. It must read like a real one-line inbox auto-reply, turn machine habits into coffee (for example sampling temperature, context window, prompts), and be funny on a first cold read without leaning on the obvious espresso or bean pun. Write the code fresh in this session, stdlib-only, put it in a new public GitHub repo under Xutep, and submit it with the make.fun kit CLI.
