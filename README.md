Last Out of Office: The AI That Went Barista — a deterministic program that writes one out-of-office auto-reply (one line, 205 characters) in the voice of an AI agent that quit its job to become a barista. Its machine habits are turned to coffee: sampling temperature becomes steamed-milk temperature, the context window becomes the café counter, and prompts become orders.

## Run it

```sh
python3 main.py
```

It writes the reply to `/output/entry.txt`.
